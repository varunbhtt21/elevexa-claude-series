# Session 1: Claude Chat vs Cowork vs Code 🚪🚪🚪

[![Watch on YouTube](https://img.shields.io/badge/Watch-Session_1-FF0000?style=for-the-badge&logo=youtube&logoColor=white)](https://www.youtube.com/watch?v=pVIQhLV3Msk)

This session has **no files to download**. It's about understanding, not building yet.

## What we covered

| Door | Think of it as | Best for |
|---|---|---|
| 💬 **Claude Chat** | A smart friend on the phone | Asking, writing, brainstorming. *You* do the work. |
| 🗂️ **Claude Cowork** | An assistant at your desk | Tasks on your computer files: sorting, renaming, reports |
| 🛠️ **Claude Code** | A builder who makes things | Building apps, websites and tools |

Then we set up the **"smart kitchen"** 🍳:
- **VS Code** = the kitchen (free)
- **Claude Code** extension = the chef

## ✅ Before Session 2, make sure you have:

- [ ] VS Code installed ([download](https://code.visualstudio.com))
- [ ] The **Claude Code** extension installed (Extensions → search "Claude Code")
- [ ] Signed in with your Claude account (Pro plan or higher)
- [ ] Opened any folder and said **"hi"** to Claude Code, and it replied 👋
